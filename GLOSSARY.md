# Календарь звонков

Сервис бронирования звонков: владелец задаёт типы встреч, гости записываются на свободные слоты без регистрации.

## Language

**Владелец**:
Единственный заданный заранее пользователь, для которого ведётся календарь.
_Avoid_: хозяин, админ, пользователь

**Гость**:
Человек, который записывается на звонок без регистрации, указывая имя и email.
_Avoid_: посетитель, клиент

**Тип встречи**:
Вид звонка с названием, описанием и длительностью; задаётся владельцем и сразу доступен гостям для записи.
_Avoid_: услуга, категория, событие

**Слот**:
Свободный интервал в календаре: длительность равна длительности выбранного типа встречи, старт — на 30-минутной сетке рабочих часов.
_Avoid_: окошко, время, интервал

**Запись**:
Подтверждённое бронирование слота гостем.
_Avoid_: бронь, встреча (в смысле события в календаре), booking
