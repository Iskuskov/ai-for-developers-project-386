Разработайте совместно с ИИ сервис для бронирования календаря

Учебный проект Хекслета: https://ru.hexlet.io/programs/ai-for-developers

## Стек

- Бэкенд: Java 21, Spring Boot
- Фронтенд: TypeScript, React
- API-контракт: TypeSpec → OpenAPI → клиентский SDK для фронтенда
- Сборка и запуск: Docker

## Сценарий использования

### Владелец календаря

1. Открывает раздел управления типами встреч.
2. Создаёт тип встречи: указывает название, описание и длительность.
3. Тип встречи сразу становится доступен гостям для записи.
4. После того как гость записался, владелец видит встречу в списке предстоящих: показываются записи всех типов, отсортированные по дате и времени.

### Гость

1. Открывает главную страницу и выбирает тип встречи.
2. Видит календарь на ближайшие 14 дней со свободными слотами: длительность слота равна длительности выбранного типа встречи.
3. Выбирает день и свободное время.
4. Вводит имя и email, подтверждает запись.
5. Занятый слот становится недоступен для записи — для всех типов встреч.

## Ограничения

- Авторизации и личных кабинетов нет: владелец календаря один и задан заранее, гость записывается без регистрации.
- Окно записи — 14 календарных дней, начиная с сегодняшнего; окно сдвигается с течением времени.
- Рабочие часы владельца: будни, 10:00–19:00 (Europe/Moscow).
- Шаг доступных стартов слотов — 30 минут.
- Одно и то же время нельзя занять дважды: пересечения интервалов запрещены, включая частичное наложение разных типов встреч. Встреча может начинаться в момент окончания предыдущей. Правило действует и для одновременных запросов.
- Данные хранятся в памяти процесса: перезапуск приложения сбрасывает все записи.
